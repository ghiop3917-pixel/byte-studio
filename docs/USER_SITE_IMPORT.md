# Импорт сайта владельца

Источник: BYTE-STUDIO.zip, переданный владельцем 11.11.2026. Архив не изменялся. Перед импортом сохранён полный снимок прежнего web/studio и crm_api.py в backups/before-user-site-*. Предыдущие браузерные проверки также сохранены там.

Текущий публичный сайт использует index.html, app.js, reference.js, film.js, polish.js, locale.js, projects.js, case-previews.js и соответствующие CSS из архива. Дизайн, анимации, четыре концепта и RU/EN сохранены. Старые демонстрационные страницы и CRM не удалены.

## Подключённая форма

intake.js подключает #contact-form к существующему POST /public/intake. Поля: контакт, задача, необязательный бюджет. Имя, направление и сроки не запрашиваются. Согласие, honeypot, idempotency request_id, ограничение частоты и транзакционная запись CRM/outbox сохранены. Ошибка не выдаётся за успешную отправку. Ручной бриф, копирование, скачивание и контакт @bytestudio_dev доступны отдельно.

Состояния отправки и форма поддерживают RU/EN. Шрифты исходного сайта сохранены локально с OFL-лицензиями, Google Fonts не вызывается. Политика безопасности разрешает необходимые исходному дизайну inline CSS-атрибуты и data-SVG; выполнение внешних и inline-скриптов не разрешено. Для /crm сохранена отдельная строгая политика.

## Проверки

82 теста unittest; tests/imported_site_smoke.py проверяет четыре проекта, оба языка, сохранение заявки, уведомление, отсутствие обязательного имени, ошибку backend и шесть размеров экрана. tests/browser_smoke.py проверяет основной путь формы и работу CRM. Проверки используют временные базы без сообщений в настоящий Telegram.

Локальный просмотр: Python crm_api.py. Публикация не выполнялась. Перед Netlify нужно подключить публичный защищённый backend: один статический архив не обеспечивает доставку заявки в локальную SQLite.

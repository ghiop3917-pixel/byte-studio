# Референсы и материалы

По просьбе владельца исследован публичный поиск Pinterest: https://www.pinterest.com/search/pins/?q=creative%20agency%20website%20design . Доступны превью; открытие самих пинов ограничено формой входа. Не выдаём исследование миниатюр за изучение анимаций конкретных пинов. Внутренний снимок — docs/design-references/pinterest-agency-reference.png. Ориентиры: выразительная типографика, крупные изображения и редакционная композиция. Дизайн и код создаются самостоятельно; чужие макеты в портфолио не копируются.

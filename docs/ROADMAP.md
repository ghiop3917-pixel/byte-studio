# План и границы готовности

Нумерация ниже продолжает рабочую последовательность этой модернизации: CRM была вынесена раньше первоначального плана интеграций.

1. Надёжное Telegram-ядро: сохранение оригиналов, долговечные очереди, outbox и восстановление.
2. CRM-ядро: единая база, клиенты, сделки, история, дедупликация, API и экспорт.
3. Анализ и контроль качества: локальные правила, проверка сомнительных сообщений, обратная связь.
4. Продажи: КП, follow-up, расчёт цены по данным владельца, подсказки по ответам, журнал действий.
5. Локальная веб-панель: CRM, воронка, документы, аналитика, состояния компонентов, источники, журналы и список резервных копий.
6. Сайт Byte Studio: утверждённая версия из архива владельца, четыре концепта, RU/EN, короткая форма с записью в локальную CRM и подготовка к Netlify.
7. Контроль качества и обслуживание: статистика источников, решения владельца, предложения без автоматического изменения правил, проверенные копии, расписание и диагностика.

## Что ещё нужно для полного публичного запуска этапов 5–6

- Согласовать опубликованные материалы, название и контакт, окончательный состав портфолио.
- Уточнить реквизиты владельца и закончить публичные документы обработки заявок.
- Подготовить VPS/backend, HTTPS, полноценную авторизацию публичной панели и политику сессий.
- Подключить форму Netlify к защищённому backend, проверить ограничения запросов с реальным reverse proxy.
- Выполнить согласованное развёртывание и проверить реальные заявки после публикации.

Полноценные AI-агенты, новые платформы, VPS-мониторинг и рыночная AI-оценка не выдаются за реализованные возможности. В панели отображаются существующие компоненты. Этап 7 добавляет расписание обслуживания и проверяемые предложения. Автоматическое изменение правил и автономные отправки не включены. Следующий этап 8 — VPS; без подтверждения не начинается.
